# 医学检验科工作日志与绩效考核APP
## 🚀 一键部署（免费）
### 方式1：Netlify（推荐，最简单）
[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/your/repo)
或手动部署：
1. 访问 https://app.netlify.com
2. 注册/登录（可用GitHub账号）
3. 把整个文件夹拖拽到浏览器窗口
4. 等待10秒 → 获得 `https://xxx.netlify.app` 网址 ✅
### 方式2：Vercel
1. 访问 https://vercel.com
2. 注册/登录
3. 点击 "Add New → Project"
4. 上传此文件夹
5. 获得 `https://xxx.vercel.app` 网址 ✅
### 方式3：GitHub Pages
1. 在GitHub创建仓库
2. 上传所有文件
3. 设置 → Pages → 选择main分支
4. 获得 `https://xxx.github.io/xxx` 网址 ✅
## 📱 手机APP使用
- 用手机浏览器打开网址
- 点击浏览器菜单 → "添加到主屏幕"
- 桌面出现APP图标，像原生APP一样使用
